# BicepTooling — User Guide

## Open in GitHub Codespaces (No Install Required)

1. Go to https://github.com/josiah1chuku/BicepTooling
2. Click the green **Code** button
3. Click the **Codespaces** tab
4. Click **Create codespace on master**
5. Wait 60 seconds — environment builds automatically

## Start Learning

cd BicepTooling/BicepTooling.Core
dotnet run -- learn

## Commands
- dotnet run -- learn          Start lessons
- dotnet run -- check <file>   Security scan
- dotnet run -- analyze <file> Full pipeline
- dotnet run -- explain <file> Plain-English explanation

## Run Tests
cd BicepTooling/BicepTooling.Tests
dotnet test
